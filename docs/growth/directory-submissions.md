> **GitHub awesome-lists are underrated backlinks.** Search GitHub for
> `awesome image tools`, `awesome design`, `awesome productivity`, find lists that
> include free web tools, and open a small PR adding sjpt.io with a one-line
> description. High-authority `github.com` links, and maintainers are receptive to
> genuinely free tools.

## Submission process (per directory)

1. Pick the **best-fit category** (Image Editing / Design / AI / Productivity).
2. Use the **exact name, URL and one-liner** from the canonical facts (see below) so listings are consistent.
3. Upload the **logo + a screenshot** (see the Product Hunt asset checklist for sizes; reuse them here).
4. If a "link back to us" badge is optional, skip it — you want *their* link to *you*, not the reverse.
5. Log it in your spreadsheet.
